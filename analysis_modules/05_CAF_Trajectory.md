# 模块 05：重构 CAF 演化轨迹

## 目标
推断 CAF 亚群之间的演化方向（如 preCAF → iCAF/mCAF 的活化轨迹），为"屏障型 CAF 如何形成"提供动态证据。

## 关键步骤
1. 多方法轨迹推断交叉验证：Monocle3 / Slingshot / PAGA / scVelo
2. 轨迹根节点选择（以正常组织成纤维细胞为起点）
3. 拟时序差异基因（DE along trajectory）+ 转录因子动态（SCENIC 扩展）
4. 轨迹→空间映射：将轨迹分支的空间分布回投到空转切片

## 输出
- 轨迹图（UMAP 投影）、拟时序基因热图
- 演化状态与空间位置关联图

## 技术要点
- 多方法交叉（图论 + 最优传输/RNA velocity），避免单一方法偏倚
- 轨迹结果需要与模块 04 的亚群注释一致（状态空间一致性检查）
