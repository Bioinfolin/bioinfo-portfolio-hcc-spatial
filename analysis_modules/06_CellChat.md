# 模块 06：细胞通讯分析（锁定信号轴 + 空间映射）

## 目标
锁定 CAF 亚群 B ↔ 免疫细胞 A 之间的关键信号轴 C，并将通讯结果**回投到空间转录组验证共定位**——这是整条管线科学假说的核心验证环节。

## 关键步骤
1. CellChat 全谱通讯推断（单细胞层面）
2. 聚焦 CAF 亚群 B → 免疫细胞 A 的配体-受体对筛选
3. 信号轴 C 锁定（通讯强度、通路富集、跨样本一致性）
4. 空间回投：信号轴配体/受体基因在空转切片的共定位验证（与免疫抑制性生态位区域重合度）
5. 候选结果输出 + 跨样本稳定性检验

## 输出
- 通讯网络图（circos / bubble / heatmap）
- 信号轴 C 候选表（`06.axisC_candidate.csv`）
- 空间共定位验证图

## 技术要点
- 锁定后的信号轴需跨样本重复检出，防单样本假阳性
- 空间共定位用邻域富集/距离分析定量（而非目测）
