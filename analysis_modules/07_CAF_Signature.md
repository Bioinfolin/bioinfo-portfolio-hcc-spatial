# 模块 07：CAF 亚群特征构建与预后验证

## 目标
将 CAF 亚群 B / 信号轴 C 的特征转为可评分的基因签名，在独立队列中验证与预后的关联——完成"机制 → 临床意义"的闭环。

## 关键步骤
1. 特征基因集构建：CAF 亚群 B 差异基因 + 信号轴 C 配体/受体基因
2. 评分方法：ssGSEA / AUCell / AddModuleScore / 平均表达 z-score（多方法交叉）
3. 队列验证：TCGA-LIHC / ICGC / GEO（单细胞队列 + 大样本 bulk 队列）
4. 生存分析（KM + Cox）、特征与临床性状关联、独立预后价值评估（多因素 Cox）

## 输出
- 特征评分分布图、KM 生存曲线、森林图
- 特征在独立队列的验证统计表

## 技术要点
- 训练/验证分离，防过度拟合（特征先锁定，再进验证队列）
- 多队列重复验证才可下预后结论
