# 模块 03：转录组差异与免疫功能评分

## 目标
评估免疫细胞功能状态（细胞毒性/耗竭/迁移/活化/增殖），验证免疫细胞 A 在肿瘤微环境中是否发生功能耗竭。

## 关键步骤
1. 免疫功能模块评分：细胞毒性、耗竭（exhaustion）、迁移、活化、增殖等基因集
2. 差异表达分析（肿瘤区 vs 正常区 / 免疫浸润区 vs 间质区）
3. 功能模块与空间位置关联："空间异质性"评分（sd/IQR）
4. 免疫细胞 A 最终裁定：综合模块 02 权重 + 本模块功能验证

## 输出
- 免疫功能评分热图（cluster × celltype）、空间分布图
- 免疫细胞 A 最终判定结论
