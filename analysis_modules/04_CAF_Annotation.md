# 模块 04：CAF 亚群注释（全谱注释 + CAF 二次聚类）

## 目标
从单细胞数据中注释肿瘤相关成纤维细胞（CAF）亚群，作为免疫抑制性生态位的"基质构建者"。

## 关键步骤
1. 单细胞全谱注释（TCGA-LIHC / ICGC / GEO 参考数据整合）
2. 成纤维细胞提取 + 二次聚类（独立于全谱的分辨率）
3. **CopyKAT 拷贝数变异验证**：区分肿瘤细胞与基质细胞，保证 CAF 身份干净（1NT-5NT 样本 + 5T 肿瘤样本）
4. CAF 亚群功能注释：ECM 重塑（COL1A1/COL1A2/FAP）、炎症（iCAF 特征）、肌成纤维（ACTA2）等维度

## 输出
- CAF 亚群聚类图（UMAP）、marker 表达
- CopyKAT 细胞预测分类 + 热图
- 亚群功能注释表

## 关键决策
- CopyKAT 与 inferCNV 交叉验证
- 恶性混淆去除是 CAF 注释质量的生死线
